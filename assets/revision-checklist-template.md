# 修改润色 Checklist

> 修改阶段逐条核对。建议先做完结构诊断（见 references/revision-checklist.md），再回来逐条核对句子级问题。

## 一、结构诊断（先做）

- [ ] 是句子问题还是结构问题？
- [ ] 如果是结构问题，已退回对应阶段重新发散
- [ ] 人物动机是否连贯
- [ ] 中段是否有推进（不垮）
- [ ] 伏笔是否全部回收
- [ ] 结尾是否回应内核
- [ ] （长篇）人设是否前后一致
- [ ] （长篇）世界观是否前后一致

---

## 二、标点

- [ ] 没有"一个逗号逗到底"
- [ ] 引号位置正确（对话标点在引号内）
- [ ] 段末标点不遗漏
- [ ] 省略号、破折号使用规范

---

## 三、对话

- [ ] 每句对话承担至少一项：推动剧情/揭示性格/传递信息/制造冲突
- [ ] 没有机械化的"他说""她道"标签
- [ ] 用动作、神态替代部分标签
- [ ] 没有对白流（整章都是对话）
- [ ] 没有自言自语过多
- [ ] 对话不水（不是生活录音）

---

## 四、描写

- [ ] 用具体细节代替形容词（"她攥紧衣角"代替"她很害怕"）
- [ ] 外貌描写点到为止，不自恋堆砌
- [ ] 挑突出的东西写，不面面俱到
- [ ] 动作描写用动词，不靠形容词

---

## 五、节奏

- [ ] 每章有一个小高潮
- [ ] 没有白开水叙事（平铺直叙）
- [ ] 段落有呼吸感（一段一个意思，不十几行不分段）
- [ ] 长句拆短
- [ ] 删除"然后""接着""于是"等过渡词堆砌
- [ ] （中长篇）每章章末有钩子
- [ ] （长篇）每卷卷末有转折

---

## 六、视角

- [ ] 视角统一（尤其开篇）
- [ ] 没有在主角视角里写主角看不到的东西
- [ ] 视角切换不频繁
- [ ] 第一人称没有"伪上帝视角"错误

---

## 七、开篇

- [ ] 主角尽快出场（500 字内）
- [ ] 开篇有冲突或悬念（1000 字内）
- [ ] 没有大段背景介绍
- [ ] 没有开篇就登场七八个人物
- [ ] 没有开篇就交代完整设定

---

## 八、逻辑

- [ ] 前后没有矛盾
- [ ] 设定没有冲突
- [ ] 没有"主角光环"过头（没有代价的胜利）
- [ ] 没有"主角开场无敌"
- [ ] 套路有变化，不雷同

---

## 九、长篇额外项

- [ ] 每章推进至少 2-3 条线（九线检查）
- [ ] 伏笔表全部回收
- [ ] 人设一致性核对
- [ ] 世界观一致性核对
- [ ] 时间线没有矛盾
- [ ] 换地图过渡合理

---

## 十、最终通读

- [ ] 大声朗读一遍（找节奏问题）
- [ ] 一周后重读（找逻辑问题）
- [ ] 让别人读（找读者视角问题）

---

## 优先级

时间有限时按这个顺序：

1. 结构问题（必须解决）
2. 人物动机
3. 节奏（章末钩子、中段推进）
4. 对话
5. 描写
6. 标点分段
