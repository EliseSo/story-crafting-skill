# 知识库使用指南

> 本 skill 的方法论不靠空想，而是从用户已有的小说写作知识库中提取。本文档说明知识库的结构以及如何从中提取方法论。

## 1. 默认行为

skill 自带的 `references/` 下已有轻量骨架版方法论，开箱即用，不依赖任何外部知识库。

## 2. 如何接入自己的知识库

用户在会话中说出知识库路径，例如：
- "用我自己的知识库 /path/to/my/kb"
- "知识库在 D:/novels/kb"

你就把所有"从知识库读取"的操作指向该路径。

如果用户的知识库结构与下方"参考结构"不同，需要让用户告诉你每个子目录对应什么主题，再按需读取。

## 3. 参考知识库结构

下面是一个推荐的知识库组织方式（用户可参考搭建，也可使用自己的现有结构）：

```
novel-writing-kb/
├── 1-写作教程/
│   ├── 1-入门与认知/        # 写作认知、生态、题材选择
│   ├── 2-基础技巧/          # 素材、大纲、爽点、对话、开篇、速度、避坑
│   ├── 3-人物与角色/        # 人设、主角、配角、反派、金手指
│   ├── 4-情节与架构/        # 情节原则、悬念节奏、爽点、结构、世界观
│   ├── 5-开篇与包装/        # 书名、简介、开篇技巧、前六万字优化
│   ├── 6-题材写作指南/      # 男频、女频、幻想、悬疑
│   ├── 7-编辑与大神经验/    # 编辑视角、大神经验
│   ├── 8-运营与投稿/        # 上架、更新、互动、完本
│   └── 9-素材与工具/        # 码字法、辅助工具
├── 2-大纲与构思/             # 大纲专项，从认知到模板
├── 3-题材与世界观/           # 按题材分类的写作指南
├── 4-拆文与对标/             # 拆解优秀作品的方法
├── 5-人物与设定/             # 人物设定专项
├── 6-描写与场景/             # 描写技法与素材
├── 7-素材百科/               # 可直接调用的素材库
├── 8-完整案例与范文/         # 大纲案例、套路范文
└── 9-AI提示词/               # AI 辅助写作的提示词
```

## 5. 如何从知识库提取方法论

当用户说"补充方法论""根据我的素材改""用知识库里的方法"时：

1. **识别当前阶段**（用户在哪个阶段）
2. **读取对应子目录的索引**（ls 该子目录，看有哪些 .md 文件）
3. **读 2-3 个最相关的文件**（不要一次读全部，按需加载）
4. **提取原则和方法**（不是照抄原文，而是提炼可执行的方法）
5. **把方法融入当前产出**（比如修改人物卡、补充节拍表）

## 7. 案例库的使用

`8-完整案例与范文/` 下有现成的大纲案例和套路范文。当用户需要参考时：

- 新手不知道怎么写大纲 -> 让他看 `8-完整案例与范文/2.1-男频玄幻爽文大纲.md` 或 `2.2-女频玄幻大纲与开篇.md`
- 不知道情节怎么设计 -> 让他看 `8-完整案例与范文/3.1-经典情节套路.md`

## 8. 当知识库不存在时的回退方案

如果用户没有自己的知识库，或指定的路径不存在：

- 使用本 skill 的 references/ 下的轻量骨架版方法论文档
- 告诉用户：当前是通用版方法论，如果需要更详细的素材，可以参考某本写作教材或自己整理后接入

## 9. 何时主动去知识库读取

- 用户明确要求"用知识库的方法"
- 用户提到具体题材，需要题材专项方法论
- 用户卡壳，需要更详细的方法论支撑
- 修改阶段发现结构问题，需要参考"卡壳解法"类文档

不要每次会话都把整个知识库读一遍。按需加载。
