# 修改润色 SOP

> 修改阶段最容易翻车的地方：新手只会逐句润色（收敛动作），但结构性问题需要退回前面阶段重新发散。先诊断，再动手。

## 1. 诊断分流（修改的第一步）

**不要直接动笔改。先问自己：这是句子问题还是结构问题？**

### 句子问题（可以直接润色）

- 用词不准
- 节奏拖
- 对话水
- 描写空
- 标点乱
- 段落长
- 视角跳

### 结构问题（必须退回前面阶段）

| 症状 | 真正的问题 | 退回到哪个阶段 |
|---|---|---|
| 人物动机断了 | 人物的 want/need 没对齐 | 阶段 1：重新做人物卡 |
| 中段垮了 | 节拍表缺中段转折 | 阶段 2：重做节拍表 |
| 伏笔没填 | 节拍表里没配对回收 | 阶段 2：补伏笔回收 |
| 结尾泄气 | 一句话故事没回答 | 阶段 1：核对内核 |
| 配角抢戏 | 配角没有独立 arc，但写得太多 | 阶段 1：配角重做人物卡 |
| 换地图生硬 | 总纲卷间过渡没设计 | 阶段 2：重做卷纲 |
| 节奏注水 | 每章没推进主线 | 阶段 2：重做章纲 |

## 2. 句子级修改清单

详见 `assets/revision-checklist-template.md`，核心要点：

### 标点
- 一个逗号逗到底 -> 拆句
- 引号位置错误 -> 对话部分通读检查
- 段末标点遗漏 -> 通读补齐

### 对话
- 删掉"他说""她道"等机械标签
- 用动作、神态替代标签
- 每句对话必须承担：推动剧情/揭示性格/传递信息/制造冲突 至少一项
- 对白流（整章都是对话）-> 把"必须告诉读者的信息"用叙述直接表达

### 描写
- 用具体细节代替形容词
  - 反例："她很害怕"
  - 正例："她攥紧了衣角，往后退了半步"
- 挑突出的东西写，不要面面俱到
- 外貌描写点到为止，不要自恋式堆砌

### 节奏
- 长句拆短
- 删除"然后""接着""于是"等过渡词堆砌
- 每章有一个小高潮
- 段落有呼吸感（一段一个意思）

### 视角
- 保持视角统一（尤其开篇）
- 不要在主角视角里写主角看不到的东西
- 第一人称慎用（长篇容易视角错误）

## 3. 结构级修改流程

如果诊断出是结构问题：

1. **不要在原地死磕**。先停下逐句润色。
2. **回到对应阶段**（见上表），重新做那一阶段的产出。
3. **把新产出和旧稿对比**，找出需要改的地方。
4. **改结构意味着改情节**，不要怕删掉大段文字。
5. **改完结构再回头做句子级润色**。

## 4. 长篇额外检查项

长篇修改比短篇/中篇多两步：

### 伏笔表核对
把所有伏笔列成表：
| 伏笔内容 | 埋设章号 | 回收章号 | 状态 |
|---|---|---|---|
| ... | ... | ... | 未回收/已回收/已废弃 |

每条伏笔都必须有回收，否则要补回收或删伏笔。

### 人设一致性核对
- 主角在卷 1、卷 2、卷 3 的行为是否符合人设？
- 重要配角的行为是否符合人设？
- 有没有"因为剧情需要就让人设崩"的地方？

### 世界观一致性核对
- 力量体系的强度递进合理吗？
- 地理、时间、势力关系有矛盾吗？
- 规则有没有前后冲突？

## 5. 修改的优先级

如果时间有限，按这个顺序改：

1. 结构问题（不解决结构，句子改得再漂亮也没用）
2. 人物动机（读者代入的前提）
3. 节奏（章末钩子、中段推进）
4. 对话（推动剧情的部分）
5. 描写（具体细节）
6. 标点分段（最后过一遍）
