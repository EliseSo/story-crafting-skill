# 结构框架选型指南

> 不要硬套模板。框架是骨架，内容是肉，骨架要和肉匹配。如果发现框架和内容长歪了，回到内核阶段重新发散。

## 1. 按驱动类型选框架

### 情节驱动型（"读者记住一件事"）

**三幕式**（最通用）
- 第一幕（25%）：建立主角现状 + 触发事件 + 第一转折点
- 第二幕（50%）：主角对抗阻碍 + 中点转折 + 最低点
- 第三幕（25%）：最终对决 + 解决 + 新状态

**英雄之旅**（适合升级/冒险/穿越）
- 平凡世界 -> 冒险召唤 -> 拒绝召唤 -> 遇见导师 -> 跨越门槛 -> 试炼盟友敌人 -> 接近深处洞穴 -> 严峻考验 -> 获得报酬 -> 回归之路 -> 复活 -> 带着仙丹回归

**起承转合**（适合中式叙事）
- 起：建立现状
- 承：发展
- 转：转折
- 合：收尾

### 人物驱动型（"读者记住一个人"）

**人物弧光骨架**
- 谎言/伤口（主角开场相信的错误信念）
- 想要 vs 需要（want 是表面目标，need 是真正成长）
- 第一转折（被迫面对谎言）
- 中点（开始动摇谎言）
- 最低点（谎言彻底崩塌）
- 真相（接受 need）
- 新自我（带着新信念行动）

**五个转折点**（适合中短篇人物弧）
- 触发事件
- 第一转折
- 中点
- 第二转折
- 高潮

## 2. 按篇幅选框架

| 篇幅 | 推荐框架 | 理由 |
|---|---|---|
| 短篇 | 节拍表（5-7 拍） | 单一转折点，不需要完整三幕 |
| 中篇 | 三幕式 + 章节级大纲 | 一条主线 + 1-2 支线 |
| 长篇 | 卷/幕结构 + 九线写法 | 跨章节状态多，需要分层 |
| 言情短篇 | 人物弧光骨架 | 读者想看人物变化 |
| 玄幻升级流 | 英雄之旅 + 换地图结构 | 升级+探险天然契合 |
| 悬疑短篇 | 起承转合 + 反转 | 转折是核心 |

## 3. 九线写法（长篇专用）

长篇至少要同时跑这九条线，否则会单调：

1. 主角升级线
2. 主角感情线
3. 配角线
4. 反派线
5. 世界观展开线
6. 伏笔线
7. 势力线
8. 装逼打脸线（爽文必备）
9. 副本/事件线

每章至少推进 2-3 条线，避免"一章只写一件事"的注水感。

## 4. 框架使用原则

1. **先有内核，再选框架**。不要因为某个框架听起来酷就用它。
2. **框架是脚手架，不是牢笼**。写到一半发现框架不合适，可以换。
3. **每章问自己：这一拍服务什么？** 如果答不出，这一拍可能是水戏。
4. **结构问题不要靠加场景解决**。加场景只会让节奏更拖。结构问题的解法是改结构。
